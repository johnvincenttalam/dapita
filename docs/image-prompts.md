# Image prompts

Prompts for the photos that replace the green placeholders. Written 21 Oct 2026, for the seed data at that date (12 shops, 41 services, 5 staff).

## How to use this

1. **Copy one prompt** into your image generator (Midjourney, ChatGPT/DALL·E, Gemini, Ideogram, Firefly…). Each prompt stands on its own: it already includes the house style.
2. **Set the aspect ratio** shown above the prompt. If your tool ignores ratios written in the prompt, set it in the tool's settings (for example `--ar 16:9` in Midjourney).
3. **Save the result with the file name shown**, all in one folder, for example `D:\Downloads\dapita-images\`. Any format and size is fine: I'll crop, resize and compress them.
4. **Send me the folder path** (or paste the images with their file names). I'll add them to the app and the mock data.

You don't need all of them at once. **Start with Set A and Set B (17 images)**; they cover the screens people see first.

**Check every image before you send it:**

- **No text, letters, logos or signs** in the picture. Generators write gibberish, and fake brand names look wrong. Regenerate if you see any.
- **Hands and faces look natural**: five fingers, nothing melted.
- **The people are fictional.** Don't use a photo of a real person or a real shop.
- **Your generator's licence allows commercial use.** These are for the prototype's fictional shops; real businesses will upload their own photos.

### House style (already inside every prompt)

> Realistic lifestyle photograph, Davao City, Philippines. Filipino people. Warm natural daylight, soft shadows. Calm, clean interiors with cream walls, natural wood, indoor plants and touches of sage green and soft peach. Gentle, inviting mood, not glossy advertising. No text, no logos, no signage, no watermark.

The greens, peach and cream tie the photos to the Dapita palette. Each shop still gets its own character, so the list doesn't look like one shop twelve times.
